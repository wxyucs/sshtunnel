# SSHTunnel Enhancement Proposals

SSHTunnel Enhancement Proposal（SEP）参考 Python Enhancement Proposal（PEP）
的组织方式，用于记录项目的重要设计、兼容性约束和演进理由。

SEP 编号一经分配不再复用。提案状态采用：

- `Draft`：仍在讨论或实现中。
- `Accepted`：设计已被接受，可能正在实现。
- `Final`：实现和文档均已完成并成为当前规范。
- `Rejected`：提案未被采用。
- `Superseded`：已被后续 SEP 替代。
